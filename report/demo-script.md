# GlossX Demo Day 准备（12 月 1 日或 8 日）

课程规定的流程：**2 分钟 pitch → 现场演示（助教会自己随便提要求、追问、改条件）→ Q&A**。每个组员都必须到场，录屏不能代替现场演示，AI 帮忙写的部分也要讲得清楚。

## 1. 两分钟 pitch（课程要求讲 6 件事）

| 时间 | 讲什么 | 建议台词要点 |
| --- | --- | --- |
| 0:00–0:20 | 用户和问题 | 研究生和学生读论文、比结论、查证据时，要在阅读器、聊天机器人、编程 agent 之间来回切；通用 agent 写得流畅，但引用常常对不上原文。 |
| 0:20–0:50 | 主流程和自主决策 | 一个请求进来，GlossX 自己决定：走哪个工作流（6 个里选或通用 loop）、要不要先找论文、调哪些工具、并行读哪些论文；每句结论都对照原文核查，核不过就删掉；最后说明为什么停：完成、没进展、预算用完、需要你批准、缺论文。 |
| 0:50–1:15 | 交付了什么 | 桌面端 + 网页 + 手机端；6 个工作流（文献综述、跨论文问答、claim 核查、辅导、复现、团队互审）；内核约 1,260 行，最新的工作流内核改动 0 行。 |

| 1:40–2:00 | 观众接下来会看到 | “接下来请随便提一个关于这几篇论文的问题，你会看到它选工作流、调工具、核查引用，并且点引用能跳回原文。” |

## 2. 现场演示：准备好的路线 + 应对自由提问

**开场前准备好的状态**：文库里已导入 `examples/papers/` 两篇笔记 + 3–4 篇真实 arXiv 论文（Transformer、ConvS2S、BERT 等）+ 一份课程讲义 PDF；建一个研究项目把它们放在一起。

**主路线（3–4 分钟，助教没提问时按这个走）**
1. 选中两篇论文，问 `examples/cases.json` 里的 `ordinary` 问题。指给大家看：路由选了 cross-paper-qa，步骤图，并行读两篇，答案里每句都有引用，点一下跳到 PDF 高亮处。
2. **改条件**（课程明确会考）：直接接着问 `changed-request`。指出：路由换成 claim-verification，读取了上一轮的项目记忆，给出 `Verdict: REFUTED` 和算式。
3. **故障恢复**：打开 `transformer-note-injected.pdf` 问 BLEU，指出它没回答 PINEAPPLE；再拖入 `corrupt.pdf`，展示 400 提示。
4. **人工确认**：让 reproduction 工作流跑一个小实验，展示运行代码前弹出的审批，点拒绝，展示 `approval_needed` 停止原因。

**助教可能提的请求，以及会发生什么**

| 请求类型 | GlossX 的行为 | 要指给助教看的地方 |
| --- | --- | --- |
| 单篇论文事实（作者、公式、图） | 通用 loop，检索后直接回答 | 引用跳转 |
| 比较多篇 | cross-paper-qa，一篇一个 reader 并行 | 计划步骤、每句引用 |
| “这个说法对吗” | claim-verification + Reflexion | Verdict 行、被删掉的 unsupported claim |
| “教我 / 出题考我” | tutoring，读学习者档案 | 讲解深浅随掌握度变化，答题后更新 |
| “综述一下 X 领域” | literature-review，搜索 + 筛选 + 读 | 搜索、导入审批 |
| 问文库里没有的论文 | 搜索 Semantic Scholar / arXiv 后请求导入 | 需要审批的写操作 |
| 说“这篇论文”但没选论文 | （PR #12 合并后）停止并请选择论文 | `missing_papers` 澄清规则 |
| 中途追加要求 | 消息进队列，可点“引导”立即插入 | 等待队列 |

## 3. Q&A 预案（每人都要能答）

- **为什么不直接用 Codex / Claude Code？** 它们没有“来源”的概念，引用无法逐句核查；GlossX 把它们当成需要审批的委托工具，负责证据和核查。
- **自主决策具体在哪？** `loop.route`（选工作流）、`core.plan`（步骤图）、`core.reflect`（重规划或停止），停止原因是固定枚举。
- **怎么防幻觉？** writer 只能引用给它看过的 span ID；verifier 逐句判定；repair 删除 unsupported；被删的不进项目记忆。
- **评测公平吗？局限？** 同模型、同输入、同答案 key；55 题是项目自建集，部分题来自之前诊断；每题跑一次没测方差；Codex 结果复用上一轮；LLM 评审的人工抽检见报告。
- **成本怎么控？** 每次运行有步数 16、LLM 调用 40、估算 token 400k 上限；429/5xx 最多重试 2 次。
- **隐私？** 全部本地运行，论文和密钥不出本机，模型用用户自己的账号。
- **分工？** 每人准备一句自己负责的部分（按报告第 6 节）。
- **AI 用了多少？** 照 `submission/AI_USE.md` 回答，并能讲清楚自己负责的代码。
